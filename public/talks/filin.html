РЕДАКЦИОННОЕ САММАРИ

О чём доклад

Презентация предлагает маркетинговый чекап по пяти блокам: смыслы, стратегия, воронки, PR и личный бренд. Полезный результат для специалиста — структурированная диагностика и план действий с ответственными и измеримыми целями.

НАША АДАПТАЦИЯ ДЛЯ ПРАКТИКИ

Как использовать в проекте

Что подготовить

Описание бизнеса, аудитория, текущий план, материалы бренда, данные о лидах/продажах и ресурсах команды.

Последовательность

  1. Провести интервью по пяти блокам и собрать доказательства.
  2. Разделить неизвестное и подтверждённые пробелы.
  3. Нанести этапы воронки и найти участок потерь.
  4. Составить план на ближайший квартал с владельцами задач и KPI.

Технический сценарий

Анкета JSON с ответом, evidence_url и confidence. Генерировать таблицу gap → действие → владелец → срок → метрика. Баллы выводить только при опубликованной шкале, иначе использовать описательные статусы.

Промт для работы

Добавьте свои файлы и контекст задачи. Промт подготовлен для этого каталога.

Проведи чекап бизнеса по смыслам, стратегии, воронке, PR и личному бренду. По каждому блоку запроси доказательства, отметь неизвестное и предложи действия. Дай план на 90 дней с ответственными, ресурсами и метриками без обещаний роста.
