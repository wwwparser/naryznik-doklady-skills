О чём доклад

Практика постановки повторяемой задачи агенту: дать свой файл, описать результат, проверить малую выборку, сверить итог с исходником и упаковать инструмент. Главная ценность — предотвращение тихих ошибок, которые скрывает красивый отчёт.

НАША АДАПТАЦИЯ ДЛЯ ПРАКТИКИ

Как использовать в проекте

Что подготовить

Одна реальная выгрузка, описание ручного процесса, пример ожидаемого результата и правила сверки.

Последовательность

  1. Выбрать частую рутинную задачу и записать требования.
  2. Сделать малый контрольный пример с известным результатом.
  3. Собрать конвейер и реестр отклонённых строк.
  4. Сверить итоги и сохранить инструкцию повторного запуска.

Технический сценарий

Python CLI: вход CSV → валидация схемы → преобразование → CSV + HTML + reconciliation.json. На join проверять дубли ключей, unmatched и изменение количества строк. Для URL отдельно утвердить правила нормализации.

Промт для работы

Добавьте свои файлы и контекст задачи. Промт подготовлен для этого каталога.

Вот выгрузка и ожидаемый результат на десяти строках. Сначала предложи план и правила сверки. Собери повторяемый инструмент с CSV и HTML на выходе. Покажи исходное и итоговое число строк, дубли, несовпадения и контрольные суммы.
